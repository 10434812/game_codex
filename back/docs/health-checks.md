# 服务健康检查

- `GET /api/health`：检查服务进程是否能响应，返回 HTTP 200；不检查数据库。
- `GET /api/ready`：通过现有连接池执行 `SELECT 1`，成功返回 HTTP 200，数据库查询失败返回 HTTP 503。响应不会包含数据库错误详情。

部署包含此接口的版本后，可在监控平台分别配置这两个地址。建议每 30 秒检查一次，单次超时设为 5 秒，连续两次失败再告警；数据库连接池等待过久时，监控平台的超时也应视为失败。

这两项检查不能证明房间创建、实时连接、对局结算或微信登录正常。上线前仍需用真实账号和设备验证完整流程；本文件不代表已经配置监控或通知渠道。
