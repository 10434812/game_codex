# 锦鲤前程小游戏客户端

原生 Canvas2D + TypeScript。入口为 `game.js`，运行代码由 `src/` 编译到 `dist/`。

## 本地构建

使用 Node.js 24 或更高版本（仓库根目录 `.nvmrc` 与 CI 保持一致）。构建会把小程序共用的本地景区图片复制到小游戏上传目录。

```bash
cd minigame
npm ci
npm test
npm run build
npm run smoke
```

截图产物：`/tmp/jinli-minigame-pages/` 和 `/tmp/jinli-minigame-smoke/`。截图使用隔离测试数据和本地素材，网络和平台能力以各自验收结果为准。

## 当前流程

- 启动页阅读隐私政策和用户协议，完成微信隐私确认后进入首页。
- 首页选择景区，创建联机房间、输入四位房间号加入，或创建本地体验局。
- 联机房间支持分享、准备、房主开局；成员准备完成后由服务端创建对局。
- 对战支持组队、解除组队、福袋和六种快捷表情。联机规则、计时和奖励由服务端确认。
- 结算后可再来一局或返回探索。商城、资料和战绩页分别接入背包、账号资料和历史记录。
- 联机会话绑定登录账号并保存活动房间，支持启动恢复、HTTP 轮询和 WebSocket 重连。
- 恢复前台重新确认微信隐私状态；撤回授权后返回授权入口。

## 微信开发者工具导入

1. 使用微信平台分配的真实**小游戏** AppID，确认账号对应的主体、权限和发行路线。
2. 按 `../docs/release/运营材料填写说明.md` 填写并确认运营信息和正式协议，再执行生成器及构建。
3. 开发者工具导入当前 `minigame/` 目录，工程类型为小游戏；保持域名校验开启。
4. 在平台配置后端 HTTPS、WSS、图片/音频下载、头像上传域名及隐私接口声明；域名以实际部署环境为准，默认资源服务为 `https://xcx.ukb88.com/`。
5. 先验证真实微信登录、昵称与头像审核，再使用两台设备完成建房到结算的一局，并核验后台流水。

`project.config.json` 的 AppID 当前等待真实账号配置；正式法律配置等待运营方确认。测试代码中的主体、AppID 和账号属于隔离用例。

## 服务端集成验收

```bash
cd ../back
npm test
npm run test:integration
```

集成脚本使用 Docker 的 `mysql:8.4`，创建独立随机端口容器，执行仓库 SQL 迁移，通过真实 HTTP、WebSocket 和数据库验证联机、结算、购买与注销；结束后清理该容器。测试账号直接创建，180 秒对局通过真实 tick 路径加速推进。真实微信登录、内容审核和真机体验使用平台凭据另行验收。
