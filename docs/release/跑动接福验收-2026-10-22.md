## 已实现

- 手指拖动控制满场跑动，松手与取消触控时停止。切后台停止提交方向，服务端在输入超过 800ms 后自动归零。
- 福袋、礼物与雷从上方掉落，700ms 预警后进入场地；接触生效、出界消失。福袋 +10、礼物 +20、雷 -10，积分最低为 0。
- 双方互相点选同意，接触后成队，出现扩散光圈与粒子闪爆；弹性连线标识队友。距离较近时双方加速 18%，分开恢复原速。
- 所有奖励和踩雷统一 2:1 联动：本人 +10 时队友 +5，本人 -10 时队友 -5。随时退出，双方同步恢复独立计分；个人积分排名结算。
- 头像、装备皮肤、光环、宠物、快捷表情、商城与资料入口接入跑动画面。角色靠近时，名字自动避让。

当前对局使用实时移动和碰撞计算积分。历史固定棋盘存档会恢复为跑动场地，并保留有效队伍、开局分数和积分明细。恢复后的方向归零。

联机服务器持有位置、掉落物、碰撞、组队关系与积分；客户端提交方向和点选意图。WebSocket 推送个人快照，断线期间使用 HTTP 同步并尝试重连。
