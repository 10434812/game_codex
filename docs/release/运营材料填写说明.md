node scripts/configure-release.mjs --operator config/operator.local.json

生成器在应用前检查全部文本与字段；遇到占位内容会列出需要补齐的位置。小程序的法律配置为统一来源，小游戏在 codegen/build 时同步，避免协议版本分叉。

生成器默认更新小程序，保留现有 AppID。未来准备小游戏时，显式传入 `--target minigame --appid wx实际小游戏AppID`，再执行 `cd minigame && npm run build`。密钥、接口权限、发行材料与平台审核结果由相应平台和主体提供。
