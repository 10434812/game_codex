# 小程序体验检查与调试

检查日期：2026-10-21。目标工程为仓库根目录原生小程序，AppID 为 `wxd7f500f3f21f15dd`。

## 本轮修正

- 首页场景卡按屏幕高度分配空间，标题和说明采用浅色，副标题允许换行。
- 首页等级、经验与经验条按实际数据展示；取消写死的高级称号与在线人数；余额只展示一次货币名称。
- 顶部昵称缩小并支持省略，移除无操作的齿轮；浅色页面使用深色标题。
- 底部导航、新手引导、对局消息、表情、商城入口与福袋面板统一计算手机底部安全区。
- 房间已加入玩家采用实色纸张卡片与深色名字；长名字省略，席位占用率改为人数含义。
- 资料页增加返回入口与独立打开时的首页回退；客服邮箱采用用户提供的实际联系方式。
- 商城返回图标改为箭头，提示文字和已使用状态提高对比度。
- 结算标题改为“本局结算”，奖励栏按可用宽度分配，避免数字挤入经验栏；本地记录提示明确设备范围。
- 移除运行时已报告无效的页面分享 JSON 字段；分享继续由现有 `showShareMenu` 和页面分享回调开启。

## 已验证

- 开发者工具 iPhone 12/13 Pro（390×844）与 iPhone 6/7/8（375×667）检查。
- 主动进入开发预览 → 首页 → 快速开始 → 房间 → 3 秒倒计时 → 180 秒本地对局 → 自动结算 → 返回首页。
- 对局实时积分变化，点击玩家头像显示组队邀请，福袋引导打开固定奖励面板。
- 对局进入商城并返回；本地余额 8,820 兑换 1,280 商品后为 7,540，商品入库。
- 资料页显示头像、昵称、操作说明，并通过返回按钮回到首页。
- 自动化：小程序 272 项、后端 137 项通过；修改文件通过 `git diff --check`。

## 待真实环境验收

- 福袋领取成功与过期竞态：模拟器已观察到限时面板及过期反馈，本轮点击落在截止之后，成功领取继续用真机验收。

- 微信登录、头像昵称审核、双设备建房与加入、断网重连、账号资产与注销：正式协议配置完成后按真实账号验收。

## 用户调试步骤

1. 微信开发者工具打开仓库根目录，确认“小程序模式”和上述 AppID，点击“编译”。
2. 点击“进入开发预览（本地体验）”，检查首页、房间、对局、结算、商城与资产页面。此入口仅在开发版出现。
3. 点击顶部“预览”，使用项目开发者微信扫码，在手机上检查字体、遮挡、滚动、触控和视频。
4. 需要定位手机错误时，点击“真机调试”并扫码，保留 Console 和 Network 中对应操作的报错。
5. 正式协议与微信后台声明完成后，再上传新版本，在公众平台设置体验版并添加体验成员。体验版按正式授权流程进入。
6. 完成真实登录与双设备联机验收，再按《小程序上线准备-2026-10-21.md》处理提审和发布。
