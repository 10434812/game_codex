# 房间异步操作保护（2026-11-13）

## 本轮新增修复

- 房间准备与开始操作共用请求锁，未完成前重复点击不会再次发送操作，准备请求期间也不能开始倒计时。
- 每次请求绑定页面生命周期、房间和账号；页面隐藏、卸载、切换房间或账号后，迟到的成功与失败响应不再更新旧页面、弹出旧错误或跳转旧对局。
- 准备请求返回后、房间详情返回后分别检查上下文。支持 API 客户端已经确认的同账号登录恢复。
- 开局等待时显示“正在开始…”，服务端未返回场次时给出重试提示，场次参数经过 URL 编码。
- 建房和邀请入房绑定请求身份及账号，强制重试不重复发送建房请求；换账号后旧成功/失败响应均丢弃。
- 初始化只在成功获取房间后标记完成，失败可以重试。离页解除旧初始化锁；旧请求完成后不能清掉新请求的连接锁。
- 建房与手动重连的收尾状态受页面生命周期保护，离页后的异步回调不再写加载状态。登录过期导致 token 清空时，仍显示重新登录入口。
